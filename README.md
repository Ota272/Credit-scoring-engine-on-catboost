# 💳 CatBoost для кредитного скоринга

Модель предсказывает, будет ли клиенту **одобрен кредит** (**1** — одобрено, **0** — отклонено) на основе анкеты с 18 признаками.

---

## 🔗 Датасет

[credit-scoring-binary](https://github.com/VGriga/credit-scoring-binary)

---

## 📊 Размер данных

* **690 строк**
* **18 признаков** + целевая переменная `Approved`

---

## 🛠️ Установка и запуск

1.  Клонируйте или скачайте репозиторий.
2.  Перейдите в папку с проектом:
    ```bash
    cd ваш/путь/к/репозиторию
    ```
3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
4.  Откройте **Jupyter Notebook** и выполните ячейки, или запустите код как обычный `.py` скрипт.

## 📈 Метрики и графики

### Метрика ROC-AUC

* **ROC-AUC: 0.970** — это **высокая** способность модели различать одобренные и отклонённые кредиты.

### ROC-кривая

Визуализирует **TPR** (чувствительность) против **FPR** (1 - специфичность) при различных порогах. Показывает компромисс между этими двумя показателями.
